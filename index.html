Create your own

Everything Claude needs to draw your GIFs is in clawd.md: the format, the seam rules and worked examples. Make your own Clawd GIF set with Claude Code. Claude draws every frame with Python code, so you just need Python installed. Your set follows the same seam rules, so it switches seamlessly with all the others.

  1. Clone the repo
    terminal
    git clone https://github.com/CodeChrisB/MyClawd.gitcd MyClawd
  2. Open Claude in the repo
    terminal
    claude
  3. Copy the prompt
    prompt for Claude
    Read clawd.md in this folder and follow it. I want to create my own Clawd GIF set.
  4. When Claude asks, explain what you want

    What should Clawd be doing in the GIF? Claude does the rest and puts your GIFs in mine/.
