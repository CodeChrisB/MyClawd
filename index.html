    Create your own

    Need one that is not there? Describe a scene, answer a few questions, and Claude draws it for you.

    1. Clone the repo
      terminal
      git clone https://github.com/CodeChrisB/MyClawd.gitcd MyClawd
    2. Open Claude in the repo
      terminal
      claude
    3. Copy the prompt
      prompt for Claude
      Read clawd.md in this folder and follow it. I want to create my own Clawd GIF set.
    4. Answer Claude's questions

      What should Clawd be doing in the GIF? Claude does the rest and puts your GIFs in mine/.

    Claude follows clawd.md: the format, the seam rules and worked examples. All you need is Python.
